
## 4. SK하이닉스 지원 전략 (2026 하반기 신규 전형 대응)

**리서치 결론: 자소서 자체가 없어지고, "AI 활용 역량 + 직무 전문성" 서식 + 반나절 실전형 심층면접으로 개편됨.**
[SK hynix Newsroom](https://news.skhynix.co.kr/ai-talent-recruit-2026-02/) · [코드프레소 분석](https://blog.codepresso.io/sk-hynix-ai-hiring-process-over-outcome/) · [A!SK 전형 가이드](https://community.linkareer.com/employment_data/4990201)

- 서류 접수: 2026-08-20 ~ 08-26 (신입 수시채용)
- 심층면접: 산재된 로그·데이터·정책 파일을 AI와 함께 분석해 문제 정의 → 명세화 → 구현 → 검증까지 실시간으로 수행. **최종 결과물뿐 아니라 프롬프트 히스토리·중간 산출물도 평가 대상.**
- 평가 축: 워크플로우 설계 / 명세화와 컨텍스트 / Agent 설계 / 오케스트레이션 / 검증과 반복 (위 2번 섹션과 동일 축)
- 별도 A!SK 전형(AI 화상면접, 2025 하반기 도입)은 AI가 직무별 질문 출제 → 영상 답변 제출 방식. 지원 공고에 이 전형이 포함되는지 별도 확인 필요.

### 준비 체크리스트
- [ ] 위 2번 섹션(AI 활용 능력)을 새 서식 항목에 맞게 재배치 — 문항이 나오면 그대로 대응 가능하게 소재 유지
- [ ] 실전 대비: 로그/데이터 뭉치를 던져주고 "문제 정의 → 명세화 → 구현 → 검증" 순서로 직접 풀어보는 연습 (AgentOps Tracer 만들 때 실제로 거친 과정과 동일한 루프이므로 재현 연습만 하면 됨)
- [ ] 프롬프트 히스토리를 남기는 습관 미리 들이기 — 면접 중 히스토리 자체가 평가 대상이므로, 평소 개발할 때도 "왜 이 프롬프트를 썼는지" 기록하는 연습
- [ ] SW/개발 직무 공고가 별도로 뜨는지, 이번 공고(설계/소자/R&D공정/양산기술)에 해당 직무가 포함되는지 채용공고 원문에서 재확인
- [ ] A!SK 화상면접 포함 여부 확인 후, 포함 시 카메라 앞에서 직무 이해도 답변하는 연습 별도 필요
