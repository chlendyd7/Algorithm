# Rotting Oranges (LeetCode 994)

- 원문: [LeetCode 994, Medium](https://leetcode.com/problems/rotting-oranges/) (링크는 이 환경에서 열어 확인하지 못했다. 아래 명세로 풀 수 있다.)
- 선정 이유: **멀티소스 BFS** 대표 문제. 프로그래머스에서 이 유형으로 확인된 문제를 못 찾았고 백준은 접속이 안 돼서 교체했다. 토마토(백준 7576)와 같은 문제.
- 우선순위: 필수. 연습 파일: [Main.java](./Main.java). 프로그래머스처럼 Solution 클래스 형태라 입출력 처리가 없다.

## 명세

m×n 격자. `0` 빈 칸, `1` 신선한 오렌지, `2` 썩은 오렌지(1≤m,n≤10). 매 분 썩은 오렌지의 상하좌우에 인접한 신선한 오렌지가 썩는다.
신선한 오렌지가 없어질 때까지 걸리는 최소 분을 반환. 처음부터 신선한 오렌지가 없으면 0, 끝까지 썩지 않는 오렌지가 남으면 -1.

## 연습 목표

썩은 오렌지를 **처음에 전부 큐에 넣고** BFS 한 번으로 끝낸다. 오렌지마다 BFS를 돌리지 않는다. 목표 복잡도 O(m×n).

## 확인할 조건 (예제 5개는 Main.java, 기대값은 기준 풀이로 확인)

- 답은 "마지막으로 썩은 칸의 분"이다. 큐에서 꺼낼 때 단계 수를 같이 관리(레벨별 반복 또는 dist 값).
- 신선한 오렌지가 0개이면 BFS 단계가 0이라도 정답은 0 (`{{0,2}}`, `{{0}}`).
- 썩은 오렌지가 없고 신선한 것만 있으면 -1 (`{{1}}`).
- 큐에 `int[]`를 넣거나 `r*m+c` 정수로 인코딩. 둘 다 써 본다.
- 입력을 직접 읽는 변형(백준 토마토)으로 풀고 싶으면 `M N` 순서(가로, 세로)에 주의한다.
