# 선인장 숨기기

- 원문: 프로그래머스 Lv2, 2025 카카오 하반기 2차 (페이지를 저장해 둔 HTML에서 예제와 제한을 가져옴)
- 우선순위: 필수. 후기 빈출인 "이분탐색/누적합 + 구현" 체급 연습. 연습 파일: [Main.java](./Main.java)

## 조건 요약

- 격자 m x n, `m*n <= 500,000`. h x w 구역은 회전 불가.
- `drops[i]`가 i+1번째 빗방울. 구역 안 칸이 **처음** 젖는 시각이 가장 늦은 위치를 고른다.
- 안 젖는 구역이 있으면 그 위치가 최우선. 동점이면 위쪽 행, 그다음 왼쪽 열.
- 그룹 #1(30%): m, n <= 50. 그룹 #2(70%): 제한 없음.

## 연습 목표

- 코딩 전에 5분: N 범위 -> 허용 복잡도를 먼저 적는다 (m*n 5e5면 O(mn) 또는 O(mn log)).
- 접근 A: 칸별 "젖는 시각" 배열 + 행 방향/열 방향 슬라이딩 윈도우 최솟값(모노토닉 덱).
- 접근 B: 시각 T를 이분탐색, "젖은 칸 = 시각 <= T"를 2D 누적합으로 세어 "젖은 칸이 0개인 구역이 있는가"를 판정.
- 안 젖는 칸의 시각은 `drops.length + 1`처럼 큰 값으로 둔다.
- Main.java의 700x700 테스트는 브루트포스를 걸러내는 용도.
