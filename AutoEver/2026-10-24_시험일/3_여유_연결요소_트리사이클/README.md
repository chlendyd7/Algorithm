# 연결요소 판정 (트리/경로/사이클) — 자체 문제

- 근거: 후기 "그래프가 나뉘어진 경우와 사이클인 경우를 고려해야 하는 DFS, 순환이면 홀/짝에 따라 n/2". 원문 접근 불가라 실제 문제 조건은 모른다. 이 문제는 그 힌트로 만든 연습용이다.
- 우선순위: 여유. 연습 파일: [Main.java](./Main.java) (틀 + 테스트 9개)

## 연습 목표

- 연결요소를 하나씩 순회하며 정점 수 `V`, 간선 수 `E`를 센다. `E = V - 1`이면 경로(트리), `E = V`이면 사이클.
- 사이클을 `if`로 하나하나 처리하지 말고 공식으로 줄인다: 길이 k의 사이클에서 가장 먼 정점까지 거리는 `k / 2`.
- n = 20만, 경로 길이 10만이면 재귀 DFS는 StackOverflow가 난다. 반복문(스택/큐 또는 이웃 따라 걷기)으로 쓴다.
- 혼자인 노드(간선 없음), 노드 2개짜리 경로 같은 경계값을 직접 확인한다.
