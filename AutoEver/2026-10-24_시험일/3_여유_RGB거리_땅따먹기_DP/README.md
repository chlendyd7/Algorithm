# RGB거리 / 땅따먹기 DP

- 근거: 후기의 DP 유형. RGB거리(백준 1149)는 백준 종료로 링크 없이 번호만 적었고, 같은 구조의 [프로그래머스 땅따먹기](https://school.programmers.co.kr/learn/courses/30/lessons/12913)(Lv2)를 함께 넣었다 (이 링크는 직접 열어 확인하지 못했다).
- 우선순위: 여유. 연습 파일: [Main.java](./Main.java) (틀 + 테스트 6개)

## 핵심

- 상태 `dp[i][직전에 쓴 색/열]`. i번째에서 c를 고르면 `dp[i][c] = cost[i][c] + (i-1번째에서 c가 아닌 것들의 최소/최대)`.
- 처음 행은 그대로 `dp[0][c] = cost[0][c]`. 답은 마지막 행의 최솟값/최댓값.
- 색이 3개든 열이 4개든 "자기 자신만 제외"하는 구조는 같다.
- 예제 기대값 96, 3, 208(백준 1149 예제), 16(땅따먹기 예제)은 기준 풀이로 확인했다.
