# 기차 선로

- 원문: 프로그래머스 Lv3, 2025 카카오 하반기 2차 (저장해 둔 HTML에서 예제와 제한을 가져옴. 선로 7종 그림은 텍스트에 없어 문제 페이지에서 확인)
- 우선순위: 여유. 어려운 쪽 문제를 만났을 때의 **부분점수 전략** 연습용. 연습 파일: [Main.java](./Main.java)

## 연습 목표

- 먼저 그룹 #1(3번 선로 없는 경우, 35%)만 통과시킨다. 못 풀어도 25분 규칙으로 끊는다.
- n*m <= 20이면 지수 시간 완전탐색이 허용된다. 후보를 전부 놓고 검사하지 말고 놓는 즉시 이웃과 연결이 맞는지 가지치기한다.
- 예제 기대값 6개는 문제 페이지의 것이다. 정답 풀이가 아니라 틀만 있다.
