# 경유지 최단경로 (자체 문제)

- 근거: 오토에버 후기 3건이 모두 "특정 지점을 거치는 최단경로 / 다익스트라 + 백트래킹(또는 플로이드 + DP)"을 말한다 (원문 일부는 접근 불가, 붙여 준 본문 기준). 실제 문제의 정확한 조건은 모른다.
- 우선순위: 필수. 연습 파일: [Main.java](./Main.java) (틀 + 테스트 10개)

## 연습 목표

- **가중치가 있으면 BFS가 아니다.** 입력을 읽고 "간선에 가중치가 있나, 노드 수는 얼마인가"부터 확인한다.
- 방법 A: 핵심 노드(s, via)에서 각각 다익스트라 -> 표 -> 순서 탐색(K ≤ 10이면 `dp[mask][last]`, K ≤ 8이면 순열도 가능).
- 방법 B: 상태 확장 다익스트라 `dist[노드][통과한 via 집합]`. 경유 필수 조건을 `visited[노드]` 하나로 막으면 틀린다.
- 합은 `long`. 간선 w ≤ 10⁹이고 경로가 길면 int를 넘는다.
- 테스트 7번은 노드를 두 번 지나야 하는 경우, 9번은 via가 t와 같은 경우, 3번은 도달 불가(-1).
