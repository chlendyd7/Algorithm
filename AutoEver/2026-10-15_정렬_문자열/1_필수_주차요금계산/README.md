# 주차 요금 계산

- 원문: [프로그래머스 Lv2](https://school.programmers.co.kr/learn/courses/30/lessons/92341)
- 우선순위: 필수. 베스트앨범으로 커버되지 않는 문자열 파싱을 보완.
- 연습 파일: [Main.java](./Main.java)

## 연습 목표

시간 문자열을 분으로 변환하고, 차량별 입차 시각과 누적 이용 시간을 관리한다. 차량 번호 오름차순으로 결과를 정렬한다. 목표 복잡도는 기록 수 R, 차량 수 V 기준 O(R + V log V).

## 확인할 조건

- 출차 기록이 없으면 23:59로 처리.
- 같은 차량이 여러 번 입출차하면 시간을 합산한 뒤 요금을 한 번 계산.
- 기본 시간 이하일 때 기본 요금만 청구.
- 초과 시간이 단위 시간으로 나누어떨어지지 않으면 올림.
- 0000처럼 앞에 0이 있는 차량 번호, 기본 요금이 0인 경우.

Main.java에 원문 예제 3개와 기대값을 넣었다. TODO를 채운 뒤 실행하고, 제출할 때는 import와 Solution 클래스만 복사한다.
