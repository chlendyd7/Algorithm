# 보석 쇼핑

- 원문: [프로그래머스 Lv3](https://school.programmers.co.kr/learn/courses/30/lessons/67258)
- 우선순위: 필수. 구명보트와 달리 연속 구간을 늘리고 줄이는 슬라이딩 윈도우.
- 연습 파일: [Main.java](./Main.java)

## 연습 목표

모든 보석 종류를 포함하는 가장 짧은 연속 구간을 찾는다. 배열 크기는 최대 100,000이므로 모든 구간을 열거하지 않는다. 두 포인터가 각각 한 방향으로 이동하는 O(N) 풀이를 목표로 한다.

## 확인할 조건

- 최단 구간 길이가 같으면 시작 번호가 작은 구간.
- 반환 인덱스는 1부터 시작.
- 보석 종류가 1개이면 [1, 1].
- 같은 보석이 여러 번 등장할 때 구간 내 빈도를 관리.
- 왼쪽을 줄여서 빈도가 0이 되면 종류 수에 반영.

Main.java의 원문 예제 4개를 통과한 뒤, 답이 배열 끝에 있는 경우도 직접 확인한다. 제출할 때는 import와 Solution 클래스만 복사한다.
