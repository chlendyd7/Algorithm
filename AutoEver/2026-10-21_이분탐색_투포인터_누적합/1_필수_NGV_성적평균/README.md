# 성적 평균

- 원문: [NGV Lv3](https://exam.hyundai-ngv.com/practice/6294)
- 우선순위: 필수. 1차원 누적합의 짧은 입문 문제.
- 연습 파일: [Main.java](./Main.java). 표준입출력 처리는 제공, averages만 직접 구현.

## 연습 목표

학생 수 N≤1,000,000, 질의 수 K≤10,000. 구간 [A,B]의 평균을 매번 순회하지 말고 누적합으로 구간 합을 O(1)에 구한다. 전체 목표 복잡도 O(N + K).

## 원문 예제

입력:

```text
5 3
10 50 20 70 100
1 3
3 4
1 5
```

출력:

```text
26.67
45.00
50.00
```

## 확인할 조건

- 질의는 1-based이며 양 끝을 포함. A=1과 A=B도 확인.
- 정수 나눗셈을 피하고 소수점 둘째 자리까지 출력.
- 누적합은 long으로 작성하는 습관을 연습. 원문 최대 합은 100,000,000이라 int도 가능하지만 범위가 커지는 변형을 대비한다.
- 입력이 많으므로 Scanner 대신 제공한 BufferedReader/StringTokenizer 틀 사용.

추가 확인: N=1, 성적 100, 질의 [1,1]의 답은 100.00.
