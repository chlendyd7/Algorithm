# 파괴되지 않은 건물

- 원문: [프로그래머스 Lv3](https://school.programmers.co.kr/learn/courses/30/lessons/92344)
- 우선순위: 여유 (2026-10-19 3차 점검에서 필수에서 강등. 2차원 차분배열은 오토에버 후기에 이력이 없고, 그 자리를 징검다리 건너기가 대신한다).
- 연습 파일: [Main.java](./Main.java)

## 먼저 1차원 차분배열 몸풀기

길이 5의 0 배열에 0-based 구간 [1,3]에 +2, [2,4]에 -1을 적용한다. 결과는 [0,2,1,1,-1]. 구간을 매번 순회하지 말고 차분배열에 경계를 표시한 뒤 누적해서 복원해본다. N+1 크기 배열의 마지막 칸은 경계 표시용이다.

## 연습 목표

스킬 수 K≤250,000, 격자 N×M≤1,000,000. 스킬마다 직사각형 전체를 순회하면 효율성 테스트를 통과하지 못한다. 각 스킬을 O(1)에 기록하고 격자를 한 번 복원하는 O(K + NM) 풀이를 목표로 한다.

## 확인할 조건

- 좌표 r2, c2까지 포함하는 구간.
- 마지막 행·열에 닿는 스킬을 위한 여분 경계 공간.
- 공격과 회복의 부호.
- 최종 내구도가 정확히 0이면 파괴.
- 파괴된 건물도 회복 스킬로 다시 살아날 수 있음.
- 중간 상태가 아니라 모든 스킬이 끝난 뒤 개수를 계산.

Main.java에 원문 예제 2개와 자체 경계 예제 2개를 넣었다. 제출할 때는 import와 Solution 클래스만 복사한다.
