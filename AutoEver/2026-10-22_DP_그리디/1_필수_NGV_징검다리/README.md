# 징검다리

- 원문: [NGV Lv3](https://exam.hyundai-ngv.com/practice/6293)
- 우선순위: 필수. 기존 계획에 이름만 있던 LIS를 보완.
- 연습 파일: [Main.java](./Main.java). lengthOfLIS를 구현.
- 프로그래머스 "징검다리 건너기"와 다른 문제: 이 문제는 LIS, 프로그래머스 문제는 이분탐색.

## 연습 목표

서쪽에서 동쪽으로 입력 순서를 유지하면서 높이가 엄격히 증가하는 돌을 최대한 많이 밟는다. 연속 구간일 필요는 없다. N≤3000이므로 먼저 O(N²) DP로 풀고, 여유가 있으면 lower_bound를 사용한 O(N log N)으로 다시 풀어본다.

## 원문 예제

```text
입력 1
5
3 2 1 4 5

출력 1
3

입력 2
6
1 3 2 4 6 5

출력 2
4
```

## 확인할 조건

- 정렬해버리면 원래 위치 순서가 사라지므로 정렬하지 않는다.
- DP의 상태는 "이 돌에서 끝나는 LIS 길이"로 정의해본다.
- N=1 → 1, [5,4,3,2,1] → 1, [1,2,3,4,5] → 5.
- 같은 높이를 허용하는 자체 변형에서는 [2,2,2] → 1. 엄격 증가와 비감소를 구별한다.
