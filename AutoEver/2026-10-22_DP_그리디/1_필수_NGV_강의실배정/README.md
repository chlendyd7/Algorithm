# 강의실 배정

- 원문: [NGV Lv3](https://exam.hyundai-ngv.com/practice/6291)
- 우선순위: 보완 필수. 종료 시간 기준의 구간 그리디를 연습.
- 연습 파일: [Main.java](./Main.java). maxLectures를 구현.

## 연습 목표

강의실 **1개**에 서로 겹치지 않는 강의를 최대한 많이 배정한다. 필요한 강의실 수를 구하는 문제가 아니다. N≤1,000,000이므로 O(N log N) 정렬+O(N) 선택을 목표로 한다.

## 원문 예제

입력:

```text
3
1 3
2 4
3 5
```

출력:

```text
2
```

## 확인할 조건

- 앞 강의 종료 시각 = 다음 강의 시작 시각이면 둘 다 배정 가능.
- 시작이 빠른 강의 또는 길이가 짧은 강의를 고르는 기준의 반례를 직접 만들어본다.
- 비교 함수는 Integer.compare로 작성.
- 긴 강의 [1,10]과 짧은 강의 [2,3], [3,4], [4,5] → 답 3.
- 모든 강의가 겹치면 1.

원문을 읽고 정렬 기준이 최적임을 설명할 수 있으면 완료. CSES Room Allocation은 모든 손님에게 방을 주는 문제이므로 이 문제와 목적이 다르다.
