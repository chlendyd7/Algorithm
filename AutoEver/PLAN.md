# AutoEver Java 코테 대비 (시험일 2026-10-24)

## 내 현재 상태
1. Python 코테는 준비돼 있음 — BFS/DFS는 문제없이 풀 수 있음
2. Java는 아직 약함
   - 클래스 설계해서 접근하는 것 자체가 낯섦
   - HashMap, 배열(`[]`) vs `List<>` 차이, 각각 프로퍼티/메서드 다른 게 헷갈림
   - 정렬(Comparator 등)을 Java로 하는 게 아직 어려움 — 연습 중
   - 프로그래머스 "베스트앨범" 풀이가 어렵게 느껴짐
3. 저번 코테 출제 유형
   - 힙(PriorityQueue) 2번 활용하는 문제
   - 모든 노드 강제 연결 + 나머지는 최단거리로 연결하는 그래프 문제 (MST)
4. 저번엔 특정 유형이 빠져서 낭패 — 유형 커버리지 구멍 조심

## 출제 경향 (웹 검색 교차검증 완료)
- 난이도: 백준 실버1~골드4 (간혹 골드1~2), 프로그래머스 Lv2 안정 + Lv3 초반
- 핵심 유형: 구현/시뮬레이션, 문자열, 정렬, 해시, 완전탐색, BFS/DFS, 그리디, 우선순위큐, MST/Union-Find
- 연도별로 다른 해엔 비트마스킹 + 이진탐색이 나온 이력도 있음 → 유형이 해마다 바뀜, 넓게 준비하는 게 맞음
- SQL/웹 문제는 일반 SW 전형에 안 나옴
- 세그먼트트리급 CP 심화 알고리즘은 출제 이력 없음

- 각 날짜 폴더의 문제 목록은 **[필수]/[여유]**로 나눠둠 — 3시간이면 [필수]만 해도 벅찰 수 있음, [여유]는 시간 남을 때만
