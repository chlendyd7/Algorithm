# AutoEver Java 코테 대비 (시험일 2026-10-24)

## 내 현재 상태
1. Python 코테는 준비돼 있음 — BFS/DFS는 문제없이 풀 수 있음
2. Java는 아직 약함
   - 클래스 설계해서 접근하는 것 자체가 낯섦
   - HashMap, 배열(`[]`) vs `List<>` 차이, 각각 프로퍼티/메서드 다른 게 헷갈림
   - 정렬(Comparator 등)을 Java로 하는 게 아직 어려움 — 연습 중
   - 프로그래머스 "베스트앨범" 풀이가 어렵게 느껴짐
3. 저번 코테 출제 유형
   - 힙(PriorityQueue) 2번 활용하는 문제
   - 모든 노드의 총 연결 비용 최소화 + 필수 연결 조건이 있는 그래프 문제 (MST 계열로 추정)
4. 저번엔 특정 유형이 빠져서 낭패 — 유형 커버리지 구멍 조심

## 출제 경향 (기존 메모 — 출처 링크가 없어 이번 점검에서 재검증하지 않음)
- 난이도: 백준 실버1~골드4 (간혹 골드1~2), 프로그래머스 Lv2 안정 + Lv3 초반
- 핵심 유형: 구현/시뮬레이션, 문자열, 정렬, 해시, 완전탐색, BFS/DFS, 그리디, 우선순위큐, MST/Union-Find
- 연도별로 다른 해엔 비트마스킹 + 이진탐색이 나온 이력도 있음 → 유형이 해마다 바뀜, 넓게 준비하는 게 맞음
- SQL/웹 문제는 일반 SW 전형에 안 나옴
- 세그먼트트리급 CP 심화 알고리즘은 출제 이력 없음

## 커버리지 보완 (2026-10-16)

문제 선정 순서: **프로그래머스 → NGV → 그 외 사이트**. [보완 문제 목록](./COVERAGE.md)에 원문 링크, 연습 파일, 우선순위를 모았다.

- 지난 시험의 "힙 2번"만으로 이중우선순위큐라고 확정하지 않는다. 최소/최대 동기화와 자원 배정의 두 힙을 각각 연습한다.
- 필수 연결 MST 변형은 필수로 승격. 이미 연결된 쌍과 반드시 설치할 유료 간선을 구분한다.
- 2026-10-19 조정: 프렌즈4블록(10/14)·디스크 컨트롤러(10/18)를 필수로 승격(폴더명 `1_필수_`로 변경), 등굣길은 정수 삼각형 다음 우선 보완, Java 배낭 경험이 없으면 기존 Knapsack 1 진행, 10/18에 선택 문제 `3_선택_ProcessTasksUsingServers` 추가, 10/23에 시간 제한 모의풀이(100분) 블록을 고정 확보. 자세한 내용은 [COVERAGE.md](./COVERAGE.md).
- 2026-10-19 2차 점검: 무인도 여행(격자 연결요소)·Rotting Oranges(멀티소스 BFS)를 10/17 필수로, k진수에서 소수 개수 구하기를 보충/수학 우선 항목으로 추가. SWEA 1267 작업순서를 필수로 승격. 10/23 1구간에서 신규 3문제를 먼저 푼다. 자세한 내용은 [COVERAGE.md](./COVERAGE.md).
- 2026-10-19 3차 점검(오토에버 후기 대조): 징검다리 건너기를 필수로 승격(이분탐색 반복 출제), 파괴되지 않은 건물은 여유로 강등, 경주로 건설(다익스트라+구현) 추가, 10/23을 100분 2문제로 변경. 스킵 목록(트라이·세그먼트 트리 등)은 후기에 출제 언급이 없어 유지. 자세한 내용은 [COVERAGE.md](./COVERAGE.md).
- 문자열 파싱, 일반 슬라이딩 윈도우, 1차원 누적합, 2차원 차분배열, LIS, 구간 그리디 문제를 추가했다.
- 하루 3시간이므로 추가 필수를 무조건 하루에 몰아 풀지 않는다. 쉬운 기존 문제를 이미 해결했다면 추가 필수부터 진행하고, 완료한 문제는 모의고사 날 다시 처음부터 풀지 않는다.
- 새 Main.java는 정답이 아닌 연습용이다. 함수 시그니처와 예제 실행 틀만 제공하며, TODO를 구현하기 전에는 UnsupportedOperationException이 발생한다.
